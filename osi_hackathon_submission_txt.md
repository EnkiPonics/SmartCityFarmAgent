An agent prototype for the aquaponics plant system SmartCityFarm e.V. in Berlin

## Approach

EnkiPonics wants to automate and enhance aquaponic plant operations to improve crop farming and establish scalable and sustainable systems for aquaponics. We are using several AI pipelines (LSTM, YOLO/Computer Vision and Bayesian Networks) to analyse the data provided by SmartCityFarms e.V. in Berlin. The data and the AI predictions is fed into an agent interface who can then give recommendations based on the data and the user query. This can help farmers who just recently ventured into aquaponics gain experience and deal with difficult operation situations. 

## Results

The SmartCityFarm Agent comes with a command line and dashboard interface. The dashboard is a convenient way for the user to access the agent.

## Next steps

This agent is just a prototype (given the short time of the hackathon). Next steps include the extension of the agent by fully automating the AI pipelines and their analyses, adding an MCP server for the agent with pre-defined commands to make results more consistent, and expanding the dashboard in a way that it will show live data and will be able to do frequent live updates.
